# ResthirnRCON

A BattlEye RCon tool for DayZ Epoch server admins.
Built with love by Deandl.

## Features

- Live player list with country flags and Steam ID resolution
- BattlEye ban management with multi-server sync
- IP ban management with auto-kick on login
- Server scheduler: timed messages, daily restarts, global tasks
- Steam Web API integration (VAC / Game ban detection)
- Player DB export / import for client admin hand-off
- Geolocation export / import (IP -> country)
- Dark + Light theme
